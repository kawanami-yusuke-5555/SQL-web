プライバシーについて

1. 集める情報

本サイトは、会員登録・入力フォーム・Cookie・アクセス解析ツール・広告を使っていません。運営者が利用者の個人情報を集めることはありません。

2. ブラウザの中に保存するデータ

本サイトは、使いやすさのために次のデータを、お使いのブラウザの「ローカルストレージ」に保存します。これらはブラウザの中だけにあり、運営者を含めてどこにも送信されません。

  • 解いた問題の記録（進捗）
  • 最後に開いた問題
  • 画面の並べ方（一覧の表示・横並び／縦並び）

書いた SQL と練習用のデータベースは、ブラウザの中で動かしているだけで、保存も送信もしません。
保存したデータは、ブラウザの設定で「サイトのデータ」を削除すると消えます。

3. 外部のサービス

  • 本サイトは GitHub Pages（GitHub, Inc. のサービス）で公開しています。ページを表示するときの通信で、IP アドレスなどが GitHub に記録されることがあります。
  • SQL を動かす仕組み（sql.js）を、cdnjs（Cloudflare, Inc. が運営する配信サービス）から読み込みます。このとき IP アドレスなどが cdnjs に送られます。

それぞれの扱いは、各社のプライバシーポリシーに従います。

4. この説明の変更

内容を変えるときは、このページを更新してお知らせします。
