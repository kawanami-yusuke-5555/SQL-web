上級 4 CTE（WITH句）

CTE をつないで会員を区分ごとに集計する

会員ごとの購入金額を求めて区分に分け、区分ごとの人数と購入金額の合計を取り出してください。購入金額は status が 'delivered' または 'shipped' の注文の quantity * unit_price の合計です（送料は含めません）。対象は customers テーブルに登録されていて、この条件の注文が1件以上ある会員だけです（customers にいない顧客ID の注文は含めません）。区分は、購入金額が 50000 円以上なら 'A'、20000 円以上なら 'B'、それ未満なら 'C' です（ちょうど 50000 円は 'A'、ちょうど 20000 円は 'B'）。列は 区分, 人数, 購入金額の合計 の順で、区分の A, B, C の順に並べます。

この問題を解く（SQLを書く）

ブラウザだけで動きます。登録は不要です。

期待される結果

この表と同じ結果になるSQLを書きましょう（列名は違っていても正解になります）。

この問題は並び順も判定します。

gradeCOUNT(*)SUM(amount)
A4271540
B13440800
C25234940

3 行

ヒント

CTE は前に書いた CTE を参照できます。1つ目の CTE で会員ごとの購入金額、2つ目の CTE で CASE を使って区分を付け、最後の SELECT で区分ごとに GROUP BY します。

模範解答と解説を見る 
WITH customer_sales AS ( SELECT c.id, SUM(oi.quantity * oi.unit_price) AS amount FROM customers c JOIN orders o ON o.customer_id = c.id JOIN order_items oi ON oi.order_id = o.id WHERE o.status IN ('delivered', 'shipped') GROUP BY c.id), classified AS ( SELECT id, amount, CASE WHEN amount >= 50000 THEN 'A' WHEN amount >= 20000 THEN 'B' ELSE 'C' END AS grade FROM customer_sales) SELECT grade, COUNT(*), SUM(amount) FROM classified GROUP BY grade ORDER BY grade

CTE をカンマでつなぐと、「会員ごとの金額 → 区分を付ける → 区分ごとに集計」のように処理を段階に分けて書けます。1つの SELECT にまとめると GROUP BY を2段重ねた副問い合わせになり、読みにくくなります。customers と結合しないと、存在しない顧客ID 51 の注文（order 69）が1人分として数えられます。
