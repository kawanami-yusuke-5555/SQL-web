中級 18 NULL処理

未登録のメールアドレスを「未登録」と表示

会員の一覧で、未登録（NULL）のメールアドレスを「未登録」と表示します。customers テーブルから、都道府県（prefecture）が大阪府の会員を取り出してください。列は id, name, メールアドレス の順です。メールアドレスは email を出しますが、NULL のときは代わりに文字列 '未登録' を出します。並び順は問いません。

この問題を解く（SQLを書く）

ブラウザだけで動きます。登録は不要です。

期待される結果

この表と同じ結果になるSQLを書きましょう（列名は違っていても正解になります）。

idnameCOALESCE(email, '未登録')
2鈴木 一郎ichiro.suzuki@example.com
12吉田 愛ai.yoshida@example.com
23森 隆未登録
35村上 涼未登録
45田中 優yu.tanaka@example.com

5 行

ヒント

COALESCE(値1, 値2) は、値1 が NULL でなければ値1を、NULL なら値2を返します。IFNULL(値1, 値2) も同じ働きです。

模範解答と解説を見る 
SELECT id, name, COALESCE(email, '未登録') FROM customers WHERE prefecture = '大阪府'

COALESCE は引数を左から見て、最初の NULL でない値を返します。画面や帳票で NULL を分かりやすい文字に置き換えるときに使います。email をそのまま出すと NULL のまま表示されます。
