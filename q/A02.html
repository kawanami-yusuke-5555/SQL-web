平均より売れている商品（CTE を2回使う）

商品ごとの売上金額を求め、その売上金額が「売れた商品の売上金額の平均」より大きい商品を取り出してください。売上は status が 'delivered' または 'shipped' の注文だけで、金額は quantity * unit_price の合計です（送料は含めません）。平均は、この条件で売上が1円以上ある商品だけの平均です（一度も売れていない商品を 0 円として平均に入れません）。平均とちょうど同じ商品は含めません。列は 商品ID（products.id）, name, 売上金額 の順です。並び順は問いません。

この問題を解く（SQLを書く）

ブラウザだけで動きます。登録は不要です。

ヒント

商品ごとの売上を CTE にしておけば、外側の SELECT で「その CTE の行」と「その CTE から計算した平均（SELECT AVG(...) FROM CTE名）」の両方に使えます。

模範解答と解説を見る 
WITH product_sales AS ( SELECT oi.product_id, SUM(oi.quantity * oi.unit_price) AS sales FROM order_items oi JOIN orders o ON o.id = oi.order_id WHERE o.status IN ('delivered', 'shipped') GROUP BY oi.product_id) SELECT p.id, p.name, ps.sales FROM product_sales ps JOIN products p ON p.id = ps.product_id WHERE ps.sales > (SELECT AVG(sales) FROM product_sales)

同じ集計を「行として使う」ところと「平均を出す」ところの2か所で使うので、CTE にしておくと集計を1回書くだけで済みます。副問い合わせで書くと同じ GROUP BY を2回書くことになり、条件を直すときに片方だけ直し忘れる原因になります。明細1行ごとの平均（AVG(quantity * unit_price)）と比べると、「商品ごとの売上の平均」とは別の値になるので結果が変わります。
