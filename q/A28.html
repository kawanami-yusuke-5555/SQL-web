カテゴリ平均より売れている商品

同じカテゴリの平均より売上金額が大きい商品を探します。全 40 商品について売上金額を求め、同じカテゴリ（products.category_id）の商品の平均売上金額より売上金額が大きい商品を取り出してください。売上は status が 'delivered' または 'shipped' の注文の明細の quantity * unit_price の合計で、一度も売れていない商品（キャンセル・返品だけの商品も）は売上 0 として平均の計算に含めます。平均と等しい商品は含めません（商品が1つだけのカテゴリは、その商品が平均と等しいので出てきません）。列は category_id, id, name, sales, category_avg の順です。category_avg はカテゴリの平均売上金額を小数第1位に ROUND した値です。並び順は問いません。

ヒント

products を基準に order_items と orders を LEFT JOIN し、SUM(CASE WHEN status が有効 THEN 金額 END) を COALESCE で 0 にして商品ごとの売上を求めます。WHERE で status を絞ると、売れていない商品の行が消えてしまいます。次に AVG(sales) OVER (PARTITION BY category_id) でカテゴリ平均を横に並べ、外側で比べます。

模範解答と解説を見る 
WITH sales AS ( SELECT p.id, p.name, p.category_id, COALESCE(SUM(CASE WHEN o.status IN ('delivered', 'shipped') THEN oi.quantity * oi.unit_price END), 0) AS sales FROM products p LEFT JOIN order_items oi ON oi.product_id = p.id LEFT JOIN orders o ON o.id = oi.order_id GROUP BY p.id, p.name, p.category_id), w AS ( SELECT *, AVG(sales) OVER (PARTITION BY category_id) AS cat_avg FROM sales) SELECT category_id, id, name, sales, ROUND(cat_avg, 1) AS category_avg FROM w WHERE sales > cat_avg

LEFT JOIN で売れていない商品を 0 として残す集計と、PARTITION BY のウィンドウ関数による「グループ平均との比較」を組み合わせています。GROUP BY と違い、ウィンドウ関数なら行を残したまま平均を横に並べられます。WHERE で status を絞ると売れていない商品が消え、平均が高く出ます（インテリアのアロマディフューザーは、売れていない花瓶を 0 として含めたときだけ平均を上回ります）。比較は丸める前の平均で行います。
