中級 26 サブクエリ（副問い合わせ）

低い評価が付いた商品

低い評価のレビューが付いたことのある商品を探します。reviews テーブル（レビュー）で、評価（rating）が 3 以下のレビューが1件以上付いたことのある商品を、products テーブルから取り出してください。ちょうど 3 のレビューも含めます。1つの商品は1行だけ出します。列は id, name, price の順です。並び順は問いません。

この問題を解く（SQLを書く）

ブラウザだけで動きます。登録は不要です。

期待される結果

この表と同じ結果になるSQLを書きましょう（列名は違っていても正解になります）。

14 行

ヒント

まず「評価 3 以下のレビューが付いた product_id の一覧」を SELECT で作り、それを WHERE id IN ( ... ) のかっこの中に入れます。

模範解答と解説を見る 
SELECT id, name, price FROM products WHERE id IN (SELECT product_id FROM reviews WHERE rating <= 3)

IN (副問い合わせ) は「かっこの中の結果のどれかに一致する行」を選びます。同じ商品に低い評価が何件あっても、商品は1行のままです。JOIN で書くと、低い評価が2件以上ある商品（信楽焼のマグカップなど）が重複して出ます。また = (副問い合わせ) にすると、SQLite ではエラーにならず最初の1件とだけ比べてしまいます。
