中級 24 CASE式

部署ごとの在籍者数と退職者数（条件付き集計）

部署ごとの在籍者数と退職者数を、1行に横に並べて集計します。employees テーブル（社員）から、部署ID（department_id）ごとに、在籍中の社員（left_on が NULL）の人数と、退職した社員（left_on が NULL でない）の人数を、横に並べて取り出してください。部署のない社員は department_id が NULL の1つのグループとして1行にします。該当者がいない場合は 0 を出します。列は department_id, 在籍中の人数, 退職者の人数 の順です。並び順は問いません。

この問題を解く（SQLを書く）

ブラウザだけで動きます。登録は不要です。

期待される結果

この表と同じ結果になるSQLを書きましょう（列名は違っていても正解になります）。

department_idSUM(CASE WHEN left_on IS NULL THEN 1 ELSE 0 END)SUM(CASE WHEN left_on IS NOT NULL THEN 1 ELSE 0 END)

ヒント

SUM(CASE WHEN 条件 THEN 1 ELSE 0 END) と書くと、条件に合う行の数を数えられます。1つの SELECT に、条件の違う集計をいくつも並べられます。

模範解答と解説を見る 
SELECT department_id, SUM(CASE WHEN left_on IS NULL THEN 1 ELSE 0 END), SUM(CASE WHEN left_on IS NOT NULL THEN 1 ELSE 0 END) FROM employees GROUP BY department_id

CASE で「条件に合う行は 1、合わない行は 0」にしてから SUM すると、グループの中で条件に合う行の数になります（条件付き集計）。COUNT(CASE ... ELSE 0 END) は 0 も「NULL でない値」として数えるので、全員の人数になってしまいます。ELSE 0 を省くと、該当者がいない部署で SUM が NULL になります。
