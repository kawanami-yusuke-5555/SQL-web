NTILE で会員を4つのグループに分ける

会員を購入金額の多い順に並べて NTILE で4つのグループ（1〜4）に分け、グループごとの人数・最小の購入金額・最大の購入金額を取り出してください。購入金額は status が 'delivered' または 'shipped' の注文の quantity * unit_price の合計です（送料は含めません）。対象は customers テーブルに登録されていて、この条件の注文が1件以上ある会員だけです。購入金額の多い会員がグループ 1 になり、同じ購入金額の会員は会員ID の小さい方を先に並べてから分けます。列は グループ番号, 人数, 最小の購入金額, 最大の購入金額 の順で、グループ番号の順に並べます。

ヒント

NTILE(4) OVER (ORDER BY ...) は、並べた行をできるだけ同じ人数の4グループに分けます。割り切れないときは、前のグループが1人ずつ多くなります。CTE で会員ごとの購入金額 → グループ番号を付ける → GROUP BY でグループごとに集計、の順に組み立てます。

模範解答と解説を見る 
WITH customer_sales AS ( SELECT c.id, SUM(oi.quantity * oi.unit_price) AS amount FROM customers c JOIN orders o ON o.customer_id = c.id JOIN order_items oi ON oi.order_id = o.id WHERE o.status IN ('delivered', 'shipped') GROUP BY c.id), tiles AS ( SELECT id, amount, NTILE(4) OVER (ORDER BY amount DESC, id) AS grp FROM customer_sales) SELECT grp, COUNT(*), MIN(amount), MAX(amount) FROM tiles GROUP BY grp ORDER BY grp

NTILE(n) は順番に並べた行を n 個のグループに等分します。人数が割り切れないときは前のグループから1人ずつ多くなるので、人数の列で確かめられます。グループの境目に同じ金額の会員がいると、どちらが前のグループに入るかが決まらないため、OVER の ORDER BY に会員ID も加えます。customers と結合しないと、存在しない顧客ID 51 が1人として入り、人数の配分が変わります。
