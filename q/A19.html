上級 19 再帰CTE

配下のカテゴリを含めたカテゴリ別売上

13 個のすべてのカテゴリについて、そのカテゴリ自身と配下のすべてのカテゴリ（子・孫）に属する商品の売上金額の合計を求めてください。売上は status が 'delivered' または 'shipped' の注文の明細の quantity * unit_price の合計です（送料は含めません）。キッチン（id 1）のように、親カテゴリに直接属する商品もあるので、自分自身の商品も含めます。売上のないカテゴリ（季節雑貨）は 0 とします。列は id, name, sales の順です。並び順は問いません。

この問題を解く（SQLを書く）

ブラウザだけで動きます。登録は不要です。

ヒント

まず再帰CTEで「(祖先のカテゴリID, 子孫のカテゴリID)」の組をすべて作ります。最初の行は各カテゴリと自分自身の組 (id, id)、次の行で子カテゴリをたどります。次に、カテゴリIDごとの売上を別のCTEで集計し、子孫のカテゴリIDで結び付けて、祖先ごとに合計します。

模範解答と解説を見る 
WITH RECURSIVE tree(ancestor_id, category_id) AS ( SELECT id, id FROM categories UNION ALL SELECT t.ancestor_id, c.id FROM tree t JOIN categories c ON c.parent_id = t.category_id), sales AS ( SELECT p.category_id, SUM(oi.quantity * oi.unit_price) AS amount FROM order_items oi JOIN orders o ON o.id = oi.order_id JOIN products p ON p.id = oi.product_id WHERE o.status IN ('delivered', 'shipped') GROUP BY p.category_id) SELECT c.id, c.name, COALESCE(SUM(s.amount), 0) AS sales FROM categories c JOIN tree t ON t.ancestor_id = c.id LEFT JOIN sales s ON s.category_id = t.category_id GROUP BY c.id, c.name

「祖先と子孫の組」の表（閉包テーブル）を再帰CTEで作ると、どの段のカテゴリでも「配下全体の合計」を同じ書き方で集計できます。自分自身との組 (id, id) を入れないと、親カテゴリに直接属する商品（竹の弁当箱など）の売上が抜け、最下層のカテゴリは 0 になります。最上位の4カテゴリの合計は、全体の売上と一致します。
