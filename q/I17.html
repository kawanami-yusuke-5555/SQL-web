中級 17 JOIN

同姓同名の会員の組（自己結合）

二重登録の疑いがある、同姓同名の会員の組を探します。customers テーブルから、名前（name）がまったく同じ会員の組を探してください。1つの組は1行だけ出し、id の小さい方を左に置きます。列は 小さい方の id, 大きい方の id, name の順です。並び順は問いません。

この問題を解く（SQLを書く）

ブラウザだけで動きます。登録は不要です。

期待される結果

この表と同じ結果になるSQLを書きましょう（列名は違っていても正解になります）。

ididname
149佐藤 花子

1 行

ヒント

customers を2回使って name が等しい行同士を結合します。同じ行同士の組や、左右を入れ替えた組が出ないように、id の大小の条件も ON に加えます。

模範解答と解説を見る 
SELECT a.id, b.id, a.name FROM customers AS a INNER JOIN customers AS b ON a.name = b.name AND a.id < b.id

自己結合の ON には、id の一致以外の条件（ここでは name の一致）も書けます。a.name = b.name だけでは自分自身との組も出てしまい、a.id <> b.id にすると (1, 49) と (49, 1) のように同じ組が2回出ます。a.id < b.id にすると1組1行になります。
