実践 10 人事分析

部署別の人件費と人員構成

（総務部長より）来年度の予算を組むので、部署ごとの人件費と、どんな人がいるか（人員の構成）をまとめてもらえますか？今日は 2026-01-01 です。

この問題を解く（SQLを書く）

ブラウザだけで動きます。登録は不要です。

自分で確認しよう

実践問題には決まった答えがありません。結果が出たら、次の点を確かめてから、問題の画面で「完了」にしましょう。

  • 退職者を含めるか決めたか（来年度の予算なら在籍者、2025年の実績なら退職者の在籍期間分も入る）。
  • 部署に所属していない社員（社長・配属前の新入社員）を、どこにも数えずに落としていないか。
  • 社員のいない部署を 0 として出したか、出さないと決めたか。
  • salary を月給とみなすか年額とみなすか、前提を依頼者に確認すべき点として挙げられるか。
  • 「人員の構成」を何で表したか（人数・管理職の数・勤続年数・年齢 など）。
  • 部署ごとの人数の合計が、社員テーブルの人数と矛盾しないか。
ヒント

「今いる人」で見るか「2025年の実績」で見るかを決めます。在籍中は left_on IS NULL です。部署のない社員や社員のいない部署も行として出すには、部署の一覧を基準に LEFT JOIN します（NULL どうしを結びつけるには IS が使えます）。

解答例を見る

解答例 1

WITH dept AS (
  SELECT id, name FROM departments
  UNION ALL
  SELECT NULL, '（部署なし）'
),
active AS (
  SELECT e.*,
         EXISTS (SELECT 1 FROM employees s
                 WHERE s.manager_id = e.id AND s.left_on IS NULL) AS is_manager
  FROM employees e
  WHERE e.left_on IS NULL
)
SELECT d.name AS 部署,
       COUNT(a.id) AS 在籍人数,
       COALESCE(SUM(a.is_manager), 0) AS 部下のいる人数,
       COALESCE(SUM(a.salary), 0) AS 月額人件費,
       CAST(ROUND(AVG(a.salary)) AS INTEGER) AS 平均月給,
       ROUND(AVG((julianday('2026-01-01') - julianday(a.hired_on)) / 365.25), 1) AS 平均勤続年数
FROM dept d
LEFT JOIN active a ON a.department_id IS d.id
GROUP BY d.id, d.name
ORDER BY d.id IS NULL, d.id

解釈: 予算のための資料なので、今日（2026-01-01）在籍している社員だけを数える。salary は月給とみなし、月額の合計を出す。全部署（社員のいない部署は 0）と「部署なし」の行を出す。構成は部下のいる人数（管理職）と平均勤続年数で表す。長所: 来年度の人件費の見込み（月額 × 12）にそのまま使える。部署なしの社員も漏れない。注意点: salary が月給かどうかは確認が必要。配属前の新入社員は配属先が決まると数字が動く。社員のいない部署は平均が NULL（空欄）になる。

解答例 2

WITH RECURSIVE months(m) AS (
  SELECT '2025-01-01'
  UNION ALL
  SELECT date(m, '+1 month') FROM months WHERE m < '2025-12-01'
),
dept AS (
  SELECT id, name FROM departments
  UNION ALL
  SELECT NULL, '（部署なし）'
),
emp_month AS (
  SELECT e.id, e.department_id, e.salary, mo.m
  FROM employees e
  JOIN months mo
    ON e.hired_on <= date(mo.m, '+1 month', '-1 day')
   AND (e.left_on IS NULL OR e.left_on >= date(mo.m, '+1 month', '-1 day'))
)
SELECT d.name AS 部署,
       COUNT(DISTINCT em.id) AS 年間の在籍者数,
       COUNT(em.id) AS 延べ人月,
       COALESCE(SUM(em.salary), 0) AS 人件費_2025年実績,
       (SELECT COUNT(*) FROM employees e
        WHERE e.department_id IS d.id AND e.left_on IS NULL) AS 期末の在籍人数,
       (SELECT COALESCE(SUM(e.salary), 0) * 12 FROM employees e
        WHERE e.department_id IS d.id AND e.left_on IS NULL) AS 来年度見込み_月給x12
FROM dept d
LEFT JOIN emp_month em ON em.department_id IS d.id
GROUP BY d.id, d.name
ORDER BY d.id IS NULL, d.id

解釈: 2025年の実績として、月末に在籍していた月ごとに月給を計上する（途中入社・途中退職の人は在籍した月の分だけ）。比較のため、期末の在籍者で計算した来年度の見込み（月給 × 12）も並べる。長所: 退職や入社で今年と来年の人件費がどう変わるかを説明できる。注意点: 社員の部署は現在の値なので、年の途中で異動した人がいても分からない。月の途中の入退社は「月末に在籍していればその月は満額」とする簡易な計算。賞与や社会保険料は含まない。

解答例 3

WITH dept AS (
  SELECT id, name FROM departments
  UNION ALL
  SELECT NULL, '（部署なし）'
),
active AS (
  SELECT id, department_id,
         (julianday('2026-01-01') - julianday(hired_on)) / 365.25 AS years
  FROM employees
  WHERE left_on IS NULL
)
SELECT d.name AS 部署,
       COUNT(a.id) AS 在籍人数,
       SUM(CASE WHEN a.years < 3 THEN 1 ELSE 0 END) AS 勤続3年未満,
       SUM(CASE WHEN a.years >= 3 AND a.years < 10 THEN 1 ELSE 0 END) AS 勤続3年以上10年未満,
       SUM(CASE WHEN a.years >= 10 THEN 1 ELSE 0 END) AS 勤続10年以上
FROM dept d
LEFT JOIN active a ON a.department_id IS d.id
GROUP BY d.id, d.name
ORDER BY d.id IS NULL, d.id

解釈: 「人員の構成」を勤続年数の分布として表す（在籍者のみ）。人件費は解答例1・2で出し、この表は構成の補足資料とする。長所: 若手が多い部署・ベテランに偏っている部署が分かり、採用や育成の予算を考える材料になる。注意点: 勤続年数は 365.25 日を1年とした概算。年齢（生年月日）は社員テーブルにないので、年齢構成は出せないことを依頼者に伝える。
