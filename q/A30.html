上級 30 総合問題

部長ごとの配下の人数と人件費

部長ごとに、配下の社員の人数と給与の合計を集計して順位を付けます。社長の直属の部下（manager_id が 1 の社員。各部の部長）それぞれについて、組織上の配下（直属の部下だけでなく、部下の部下… もすべて）にいる在籍中の社員（left_on が NULL）の人数と、その給与（salary）の合計を求め、人数の多い順に順位を付けてください。部長本人は人数にも給与にも含めません。配下は department_id ではなく manager_id のつながりでたどります（部署のない社員も、上司がいれば配下に含めます）。順位は人数の多い順で、同じ人数なら同じ順位とし、次の順位は飛ばします（RANK の付け方）。列は id, name, members, total_salary, rank の順です。rank の小さい順、同じ rank なら id の小さい順に並べます。

ヒント

再帰CTEで「(部長の id, 配下の社員の id)」の組を作ります。最初の行は manager_id = 1 の社員と自分自身の組、次の行で manager_id をたどって部下を足していきます。その後、部長本人の行と退職者を除いて部長ごとに COUNT・SUM し、RANK() OVER (ORDER BY 人数 DESC) で順位を付けます。

模範解答と解説を見る 
WITH RECURSIVE sub(head_id, member_id) AS ( SELECT id, id FROM employees WHERE manager_id = 1 UNION ALL SELECT s.head_id, e.id FROM sub s JOIN employees e ON e.manager_id = s.member_id), agg AS ( SELECT s.head_id, COUNT(*) AS members, SUM(e.salary) AS total_salary FROM sub s JOIN employees e ON e.id = s.member_id WHERE s.member_id <> s.head_id AND e.left_on IS NULL GROUP BY s.head_id) SELECT h.id, h.name, a.members, a.total_salary, RANK() OVER (ORDER BY a.members DESC) AS rank FROM employees h JOIN agg a ON a.head_id = h.id ORDER BY rank, h.id

再帰CTEで組織をたどり、集計し、ウィンドウ関数で順位を付ける、という3段の組み合わせです。部署（department_id）で数えると、総務部長の配下にいる部署なしの新入社員が漏れ、退職者のいる部も数が変わります。直属の部下だけを数えると、係長の下にいる社員が抜けます。人数が同じ部長が2組あるので、ROW_NUMBER では同じ人数なのに順位が分かれてしまいます。
