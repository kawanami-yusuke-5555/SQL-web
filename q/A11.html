会員ごとの購入額の累計（同じ日の注文に注意）

会員ID が 2 と 3 の会員について、注文ごとの金額と、その会員の購入額の累計を取り出してください。対象は status が 'delivered' または 'shipped' の注文だけで、注文の金額は明細の quantity * unit_price の合計です（送料は含めません）。累計は会員ごとに 0 から数え直し、注文日の古い順に足していきます。同じ日に複数の注文があるときは注文ID の小さい方を先に足し、1注文ずつ累計を増やします。列は customer_id, 注文ID（orders.id）, ordered_on, 注文の金額, 累計 の順で、customer_id の小さい順、同じ会員の中では注文日の古い順、同じ日なら注文ID の小さい順に並べます。

ヒント

OVER (PARTITION BY 会員 ORDER BY 注文日, 注文ID) で、会員ごとに区切った累計になります。ORDER BY を注文日だけにすると、同じ日の注文は「同順位の仲間」として一度に足されるので、2つの注文に同じ累計が付いてしまいます。

模範解答と解説を見る 
WITH order_totals AS ( SELECT o.customer_id, o.id, o.ordered_on, SUM(oi.quantity * oi.unit_price) AS total FROM orders o JOIN order_items oi ON oi.order_id = o.id WHERE o.status IN ('delivered', 'shipped') AND o.customer_id IN (2, 3) GROUP BY o.customer_id, o.id, o.ordered_on) SELECT customer_id, id, ordered_on, total, SUM(total) OVER (PARTITION BY customer_id ORDER BY ordered_on, id) AS running_total FROM order_totals ORDER BY customer_id, ordered_on, id

ウィンドウに ORDER BY を書いたときの既定の範囲は「先頭から、今の行と ORDER BY の値が同じ行（ピア）まで」（RANGE）です。会員3 は 2025-03-15 に2件（order 35 と 36）注文しているので、ORDER BY ordered_on だけだと2件とも「2件分を足した後の累計」になります。ORDER BY に注文ID を加えて行の順番を一意にするか、ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW で1行ずつ足すように指定します。
