中級 46 集合演算

要対応の商品リスト（UNION）

在庫切れの商品と評価の低い商品をまとめて、要対応の商品リストを作ります。次の2つの条件の「どちらか（または両方）」に当てはまる商品の一覧を作ってください。(1) products テーブルで在庫（stock）が 0 の商品。(2) reviews テーブルでの平均評価（rating の平均）が 3.0 以下の商品（ちょうど 3.0 も含みます）。両方に当てはまる商品も1行だけ出します。列は id, name の順です。並び順は問いません。

この問題を解く（SQLを書く）

ブラウザだけで動きます。登録は不要です。

期待される結果

この表と同じ結果になるSQLを書きましょう（列名は違っていても正解になります）。

idname
5信楽焼のマグカップ
12ステンレス片手鍋
18折りたたみテーブル
22ペンダントライト
332025年手帳
40ホーローケトル

6 行

ヒント

(1) と (2) をそれぞれ SELECT id, name ... で書き、UNION でつなぎます。(2) は reviews を GROUP BY product_id して HAVING で絞り、products と JOIN して name を出します。

模範解答と解説を見る 
SELECT id, name FROM products WHERE stock = 0 UNION SELECT p.id, p.name FROM products p JOIN reviews r ON r.product_id = p.id GROUP BY p.id, p.name HAVING AVG(r.rating) <= 3.0

UNION は2つの SELECT の結果を縦につなげ、重複した行を1つにまとめます。つなぐ SELECT どうしは列の数をそろえます。信楽焼のマグカップは在庫0で平均評価も 3.0 なので、UNION ALL だと2回出ます。< 3.0 にすると平均がちょうど 3.0 のステンレス片手鍋が漏れます。
