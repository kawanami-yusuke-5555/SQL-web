中級 11 JOIN

一度も注文していない会員

まだ一度も注文していない会員を探します。customers テーブル（会員）と orders テーブル（注文）を使って、注文が1件もない会員を取り出してください。status は問わず、キャンセルした注文が1件でもある会員は「注文がある」とみなして含めません。列は id, name の順です。並び順は問いません。

この問題を解く（SQLを書く）

ブラウザだけで動きます。登録は不要です。

期待される結果

この表と同じ結果になるSQLを書きましょう（列名は違っていても正解になります）。

idname
8中村 翔
23森 隆
41藤井 学
46三浦 陸
47藤原 葵
48岡本 蓮
50松田 翼

7 行

ヒント

LEFT JOIN は、相手が見つからない行も残し、相手側の列を NULL にします。「相手側の id が NULL の行」が、相手のいない行です。

模範解答と解説を見る 
SELECT c.id, c.name FROM customers AS c LEFT JOIN orders AS o ON o.customer_id = c.id WHERE o.id IS NULL

LEFT JOIN では左のテーブル（customers）の行がすべて残り、注文のない会員は o の列がすべて NULL になります。そこを WHERE o.id IS NULL で選びます。INNER JOIN だと注文のない会員は最初から消えるので 0 行になります。ON に status の条件を足すと、キャンセルしかない会員まで「注文なし」に入ってしまいます。
