上級 1 CTE（WITH句）

WITH 句で注文ごとの合計を作る

注文ごとの合計金額を WITH 句で求め、金額の大きい注文を探します。orders テーブル（注文）と order_items テーブル（注文明細）から、明細の合計金額が 12000 円以上の注文を取り出してください。対象は status が 'delivered' または 'shipped' の注文だけで、合計金額は明細の quantity * unit_price の合計です（送料は含めません）。ちょうど 12000 円の注文も含めます。列は 注文ID（orders.id）, customer_id, ordered_on, 合計金額 の順です。並び順は問いません。まず WITH 句で「注文ごとの合計金額」の表を作り、そこから絞り込んでみましょう。

ヒント

WITH 名前 AS (SELECT ...) と書くと、その SELECT の結果に名前を付けて、後ろの SELECT で表のように使えます。CTE の中で GROUP BY して合計を出し、外側の SELECT の WHERE で 12000 以上に絞ります。

模範解答と解説を見る 
WITH order_totals AS ( SELECT o.id, o.customer_id, o.ordered_on, SUM(oi.quantity * oi.unit_price) AS total FROM orders o JOIN order_items oi ON oi.order_id = o.id WHERE o.status IN ('delivered', 'shipped') GROUP BY o.id, o.customer_id, o.ordered_on) SELECT id, customer_id, ordered_on, total FROM order_totals WHERE total >= 12000

WITH 句（CTE）は、副問い合わせに名前を付けて先に書いておく書き方です。「注文ごとの合計」という途中の表に名前が付くので、外側の SELECT が普通の表と同じように読めます。この問題は HAVING でも書けますが、途中の表を何度も使ったり、段階を重ねたりする次の問題から CTE の便利さが効いてきます。キャンセルされた 12000 円の注文（order 124）が混ざらないよう、status の条件は CTE の中で付けます。
