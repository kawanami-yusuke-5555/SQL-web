上級 26 連続期間・欠番

連続購入が3か月以上の期間

顧客ごとに、有効な注文（status が 'delivered' または 'shipped'）があった月が 3 か月以上続いた期間を求めてください。「続いた」とは月の番号が1つずつ続いていることで、同じ月に何回注文しても1か月と数えます（2025年8月は注文が休止されているため、7月と9月は続いていません）。列は customer_id, start_month, end_month, months の順です。start_month と end_month は期間の最初と最後の月（'2025-01' の形式の文字列）、months は期間の月数（整数）です。ちょうど 3 か月の期間も含めます。customer_id の小さい順、同じ顧客なら start_month の古い順に並べます。

ヒント

まず顧客と月の番号の組を重複なしで取り出します。次に「月の番号 - ROW_NUMBER() OVER (PARTITION BY customer_id ORDER BY 月の番号)」を計算すると、続いている月どうしは同じ値になります。その値と customer_id で GROUP BY し、MIN・MAX・COUNT で期間を求めて、HAVING で 3 か月以上を選びます。月の文字列は printf('2025-%02d', 月の番号) で作れます。

模範解答と解説を見る 
WITH m AS ( SELECT DISTINCT customer_id, CAST(strftime('%m', ordered_on) AS INTEGER) AS mon FROM orders WHERE status IN ('delivered', 'shipped')), g AS ( SELECT customer_id, mon, mon - ROW_NUMBER() OVER (PARTITION BY customer_id ORDER BY mon) AS grp FROM m) SELECT customer_id, printf('2025-%02d', MIN(mon)) AS start_month, printf('2025-%02d', MAX(mon)) AS end_month, COUNT(*) AS months FROM g GROUP BY customer_id, grp HAVING COUNT(*) >= 3 ORDER BY customer_id, start_month

連続した値は「値 - 連番」が一定になる性質を使うと、1つのグループにまとめられます（gaps and islands の定番の解き方）。例えば 1,2,3 月と 5,6 月は、月 - 連番がそれぞれ 0 と 1 になります。月を DISTINCT にしないと、同じ月の2回目の注文で連番だけが進み、続いている月が別のグループに分かれてしまいます。
