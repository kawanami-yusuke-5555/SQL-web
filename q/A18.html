上級 18 再帰CTE

社長から各社員までの経路

組織図をたどって、社員ごとに社長からの経路と階層を求めます。employees テーブル（manager_id が上司の社員ID、社長は manager_id が NULL）を使い、在籍中の社員（left_on が NULL）それぞれについて、組織の何段目にいるかと、社長から本人までの経路を求めてください。列は id, name, level, path の順です。level は社長を 1、社長の直属の部下を 2 …とします。path は社長から本人までの社員名を、上の人から順に ' > '（前後に半角スペース）でつないだ文字列です（例: '大西 正樹 > 佐藤 恵子'）。社長の path は社長の名前だけです。並び順は問いません。

ヒント

最初の行は manager_id IS NULL の社員（level 1、path は自分の名前）。次の行は「manager_id が直前の社員の id である社員」を JOIN し、level + 1、path || ' > ' || 名前 とします。在籍中かどうかの絞り込みは、最後の SELECT で行います。

模範解答と解説を見る 
WITH RECURSIVE org(id, name, level, path, left_on) AS ( SELECT id, name, 1, name, left_on FROM employees WHERE manager_id IS NULL UNION ALL SELECT e.id, e.name, o.level + 1, o.path || ' > ' || e.name, e.left_on FROM employees e JOIN org o ON e.manager_id = o.id) SELECT id, name, level, path FROM org WHERE left_on IS NULL

再帰の各段で「上司の path に自分の名前を足す」ので、上から順の経路が積み上がります。名前を前に足す（e.name || ' > ' || o.path）と、本人から社長へ向かう逆順になります。組織は最大4階層で、深さはデータによって違いますが、再帰CTEなら段数を決めずにたどれます。
