RANK と DENSE_RANK の違い

会員ごとの注文件数を数え、件数の多い順の順位を RANK と DENSE_RANK の両方で付けてください。注文件数は status が 'delivered' または 'shipped' の注文だけを数え、customers テーブルに登録されている会員だけを対象にします。取り出すのは、DENSE_RANK の順位が 5 以内の会員です（5位の会員が複数いれば全員）。列は 会員ID（customers.id）, name, 注文件数, RANK の順位, DENSE_RANK の順位 の順で、注文件数の多い順、同じ件数なら会員ID の小さい順に並べます。

ヒント

RANK は同じ値に同じ順位を付け、その人数分だけ次の順位を飛ばします（1, 2, 2, 4）。DENSE_RANK は飛ばしません（1, 2, 2, 3）。ウィンドウ関数の結果は同じ SELECT の WHERE では使えないので、CTE（または FROM 句の副問い合わせ）で順位を付けてから外側で絞り込みます。

模範解答と解説を見る 
WITH order_counts AS ( SELECT c.id, c.name, COUNT(*) AS cnt FROM customers c JOIN orders o ON o.customer_id = c.id WHERE o.status IN ('delivered', 'shipped') GROUP BY c.id, c.name), ranked AS ( SELECT id, name, cnt, RANK() OVER (ORDER BY cnt DESC) AS rnk, DENSE_RANK() OVER (ORDER BY cnt DESC) AS drnk FROM order_counts) SELECT id, name, cnt, rnk, drnk FROM ranked WHERE drnk <= 5 ORDER BY cnt DESC, id

2位が2人いると、RANK では次が 4位、DENSE_RANK では次が 3位になります。「上位5位まで」という同じ言葉でも、RANK で絞るか DENSE_RANK で絞るかで出てくる人数が変わります。WHERE はウィンドウ関数より先に処理されるため、WHERE DENSE_RANK() OVER (...) <= 5 とは書けず、CTE で順位を付けてから外側で絞ります。キャンセルを含めて数えると件数が変わる会員がいるので、status の条件も忘れないようにします。
