月別売上の累計と前月差（8月も含む）

2025年1月〜12月の各月の売上金額と、1月からの累計、前月との差を求めてください。売上は status が 'delivered' または 'shipped' の注文の明細の quantity * unit_price の合計です（送料は含めません）。注文のない8月も売上 0 の行として含めます（12 行）。列は month（'2025-01' の形式の文字列）, sales, cumulative_sales, diff_from_prev の順です。diff_from_prev は「その月の売上 - 前月の売上」で、前月のない1月は NULL とします（9月は8月の 0 と比べます）。month の古い順に並べます。

ヒント

再帰CTEで月の一覧を作り、月別の売上（CTE で集計）を LEFT JOIN して COALESCE で 0 にします。そのうえで SUM(…) OVER (ORDER BY month) で累計、LAG(…) OVER (ORDER BY month) で前月の売上を求めます。

模範解答と解説を見る 
WITH RECURSIVE months(month_start) AS ( SELECT '2025-01-01' UNION ALL SELECT date(month_start, '+1 month') FROM months WHERE month_start < '2025-12-01'), monthly AS ( SELECT strftime('%Y-%m', o.ordered_on) AS month, SUM(oi.quantity * oi.unit_price) AS sales FROM orders o JOIN order_items oi ON oi.order_id = o.id WHERE o.status IN ('delivered', 'shipped') GROUP BY month), filled AS ( SELECT strftime('%Y-%m', m.month_start) AS month, COALESCE(s.sales, 0) AS sales FROM months m LEFT JOIN monthly s ON s.month = strftime('%Y-%m', m.month_start)) SELECT month, sales, SUM(sales) OVER (ORDER BY month) AS cumulative_sales, sales - LAG(sales) OVER (ORDER BY month) AS diff_from_prev FROM filled ORDER BY month

再帰CTEで「すべての月」をそろえてからウィンドウ関数を使うのがポイントです。月をそろえずに LAG を使うと、9月の「前の行」が7月になり、休止した8月を飛ばした差になってしまいます。LAG に既定値 0 を渡す（LAG(sales, 1, 0)）と、1月の差が NULL ではなく1月の売上そのものになります。
