文字の出現回数を数える（replace・length）

商品名に特定の文字がいくつ含まれるかを数えます。products テーブルから、商品名（name）に長音記号「ー」が含まれる商品について、「ー」がいくつ含まれるかを数えてください。「ー」が1つも含まれない商品は出しません。列は id, name, 個数 の順です。個数の多い順に並べ、同じ個数なら id の小さい順に並べます。

この問題を解く（SQLを書く）

ブラウザだけで動きます。登録は不要です。

ヒント

replace(name, 'ー', '') で「ー」を消した文字列が作れます。元の文字数（length）から消したあとの文字数を引くと、消えた文字の数になります。

模範解答と解説を見る 
SELECT id, name, length(name) - length(replace(name, 'ー', '')) AS cnt FROM products WHERE name LIKE '%ー%' ORDER BY cnt DESC, id

SQL には「文字の出現回数」を直接数える関数がないので、replace で消して length の差を取るのが定番の方法です（SQLite の length は文字数を返します）。instr(name, 'ー') は「最初に現れる位置」なので個数ではありません。LIKE だけでは含むかどうかしか分からず、「ー」が2つあるホーローケトルなどを区別できません。
