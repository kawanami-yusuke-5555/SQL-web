上級 21 グループ内上位N件

カテゴリごとの売れ筋 上位2位（同数は含める）

商品のカテゴリ（products.category_id）ごとに、販売数量の多い商品の上位 2 位までを求めてください。販売数量は、status が 'delivered' または 'shipped' の注文の明細の quantity の合計です。対象はこの条件で1個以上売れた商品だけです。同じ販売数量の商品は同じ順位とし、2位が同数で複数あるときはすべて含めます（順位は RANK の付け方で、1位が2つなら次は3位）。列は category_id, product_id, name, total_quantity, rank の順です。category_id の小さい順、同じカテゴリの中では rank の小さい順、同じ rank なら product_id の小さい順に並べます。

ヒント

まず CTE で商品ごとの販売数量を集計し、次に RANK() OVER (PARTITION BY category_id ORDER BY 販売数量 DESC) で順位を付けて、rank <= 2 を選びます。ROW_NUMBER は同数でも別の番号を付けるので、同数の商品が漏れます。

模範解答と解説を見る 
WITH qty AS ( SELECT p.category_id, p.id AS product_id, p.name, SUM(oi.quantity) AS total_quantity FROM order_items oi JOIN orders o ON o.id = oi.order_id JOIN products p ON p.id = oi.product_id WHERE o.status IN ('delivered', 'shipped') GROUP BY p.category_id, p.id, p.name), ranked AS ( SELECT *, RANK() OVER (PARTITION BY category_id ORDER BY total_quantity DESC) AS rnk FROM qty) SELECT category_id, product_id, name, total_quantity, rnk AS rank FROM ranked WHERE rnk <= 2 ORDER BY category_id, rnk, product_id

「上位N位まで（同数は含める）」は RANK で順位を付けて rank <= N を選びます。洋食器（category 11）では2位が同数で2商品あり、このカテゴリだけ3行になります。ROW_NUMBER を使うと同数のどちらか一方しか残らず、どちらが残るかも決まりません。キャンセル・返品の明細を含めると、数量と順位が変わります。
