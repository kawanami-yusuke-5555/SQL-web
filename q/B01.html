初級 1 列の指定と別名

列を選んで名前を付ける

SELECT で必要な列だけを選び、見出し（別名）を付ける練習です。categories テーブル（商品カテゴリ）の全ての行について、カテゴリ名（name）と親カテゴリのID（parent_id）を取り出してください。列は name, parent_id の順で、それぞれ「カテゴリ名」「親カテゴリID」という別名を付けます。並び順は問いません。

この問題を解く（SQLを書く）

ブラウザだけで動きます。登録は不要です。

期待される結果

この表と同じ結果になるSQLを書きましょう（列名は違っていても正解になります）。

ヒント

列は SELECT のあとにカンマ区切りで、出したい順に書きます。別名は「列名 AS 別名」です。

模範解答と解説を見る 
SELECT name AS カテゴリ名, parent_id AS 親カテゴリID FROM categories

SELECT に書いた順番で列が並び、AS で結果の列に見出し（別名）を付けられます。答え合わせでは列名は比べませんが、列の数と順番は比べます。parent_id が NULL の行は親のない最上位のカテゴリです。
