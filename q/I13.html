中級 13 JOIN

新しい会員の有効な注文件数（ON に条件を書く）

新しく登録した会員ごとに、有効な注文の件数を数えます（0 件の会員も含めます）。2025-09-01 以降に登録した会員（customers.registered_on が '2025-09-01' 以上）の全員について、有効な注文（status が 'delivered' または 'shipped'）の件数を取り出してください。有効な注文が1件もない会員（注文がない会員、キャンセルした注文しかない会員）も、件数 0 として1行に含めます。列は customers.id, customers.name, 有効な注文の件数 の順です。並び順は問いません。

この問題を解く（SQLを書く）

ブラウザだけで動きます。登録は不要です。

期待される結果

この表と同じ結果になるSQLを書きましょう（列名は違っていても正解になります）。

idnameCOUNT(o.id)

42西村 結衣2

ヒント

LEFT JOIN の相手側（orders）の条件を WHERE に書くと、相手のいない行（NULL の行）まで消えてしまいます。相手側の条件は ON に書きましょう。

模範解答と解説を見る 
SELECT c.id, c.name, COUNT(o.id) FROM customers AS c LEFT JOIN orders AS o ON o.customer_id = c.id AND o.status IN ('delivered', 'shipped') WHERE c.registered_on >= '2025-09-01' GROUP BY c.id, c.name

ON に書いた条件は「どの注文を結合するか」を決めるだけなので、条件に合う注文がない会員も NULL の行として残り、COUNT(o.id) が 0 になります。status の条件を WHERE に書くと、o.status が NULL の行が除かれ、件数 0 の会員が消えます。条件を書かないと、キャンセルした注文も数えられます。
