中級 27 サブクエリ（副問い合わせ）

部下のいない社員（NOT IN と NULL）

部下のいない社員を、副問い合わせで探します。employees テーブル（社員）から、部下が1人もいない社員（だれの manager_id にも自分の id が入っていない社員）を取り出してください。退職者も含めます。列は id, name の順です。並び順は問いません。なお、社長（employee 1）は上司がいないため manager_id が NULL です。

この問題を解く（SQLを書く）

ブラウザだけで動きます。登録は不要です。

ヒント

「上司として登場する id の一覧」を副問い合わせで作り、NOT IN で除きます。その一覧に NULL が混ざるとどうなるかに注意しましょう。

模範解答と解説を見る 
SELECT id, name FROM employees WHERE id NOT IN (SELECT manager_id FROM employees WHERE manager_id IS NOT NULL)

x NOT IN (a, b, NULL) は「x <> a AND x <> b AND x <> NULL」の意味になり、x <> NULL が不明（NULL）になるため、どの行も選ばれません。manager_id には社長の NULL があるので、副問い合わせで IS NOT NULL を付けて NULL を除く必要があります。付け忘れると 0 行になります。
