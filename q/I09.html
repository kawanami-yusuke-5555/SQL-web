中級 9 JOIN

高額商品とカテゴリ名

高額商品の一覧に、テーブルを結合してカテゴリ名を付けます。products テーブル（商品）と categories テーブル（カテゴリ）を結合して、価格（price）が 10000 円以上の商品の、商品ID・商品名・カテゴリ名を取り出してください。商品の category_id が、カテゴリの id を指しています。列は products.id, products.name, categories.name の順です。並び順は問いません。

この問題を解く（SQLを書く）

ブラウザだけで動きます。登録は不要です。

期待される結果

この表と同じ結果になるSQLを書きましょう（列名は違っていても正解になります）。

idnamename
18折りたたみテーブル家具
19ブックシェルフ家具
21フロアライト照明
22ペンダントライト照明
27万年筆筆記具

5 行

ヒント

FROM products AS p JOIN categories AS c ON 結合の条件 で2つのテーブルをつなぎます。同じ名前の列（id, name）は「p.name」のようにテーブル名（別名）を付けて区別します。

模範解答と解説を見る 
SELECT p.id, p.name, c.name FROM products AS p INNER JOIN categories AS c ON c.id = p.category_id WHERE p.price >= 10000

JOIN の ON には「どの列とどの列が対応するか」を書きます。ここでは商品の category_id とカテゴリの id です。ON c.id = p.id のように対応しない列同士をつなぐと、まったく関係のない行が組み合わされます（今回は0行になります）。
