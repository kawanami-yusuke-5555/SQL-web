中級 21 CASE式

注文の状態を日本語で表示

注文の状態（status）の英語の値を、日本語の表示に置き換えます。orders テーブルから、注文日（ordered_on）が 2025-12-12 以降（12月12日を含む）の注文を取り出してください。列は id, ordered_on, 状態 の順です。状態は status を次のように日本語に置き換えます: 'delivered' → '配達済み'、'shipped' → '発送済み'、'cancelled' → 'キャンセル'、'returned' → '返品'。並び順は問いません。

この問題を解く（SQLを書く）

ブラウザだけで動きます。登録は不要です。

期待される結果

この表と同じ結果になるSQLを書きましょう（列名は違っていても正解になります）。

ヒント

CASE 列名 WHEN 値1 THEN 結果1 WHEN 値2 THEN 結果2 ... END で、列の値ごとに別の値を返せます。

模範解答と解説を見る 
SELECT id, ordered_on, CASE status WHEN 'delivered' THEN '配達済み' WHEN 'shipped' THEN '発送済み' WHEN 'cancelled' THEN 'キャンセル' WHEN 'returned' THEN '返品' END FROM orders WHERE ordered_on >= '2025-12-12'

CASE 式は、条件に合った最初の WHEN の THEN の値を返す「式」なので、SELECT の列として使えます。どの WHEN にも当てはまらず ELSE もないときは NULL になります。WHEN を1つ書き忘れると、その状態の注文の列が NULL になります。
