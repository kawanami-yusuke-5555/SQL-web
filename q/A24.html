最上位カテゴリ × 四半期の売上表

最上位のカテゴリ（parent_id が NULL の4カテゴリ）ごとに、2025年の四半期別の売上金額を1行に横に並べてください。商品は、属するカテゴリをさかのぼった最上位のカテゴリに集計します（カテゴリは最大3階層で、最上位のカテゴリに直接属する商品もあります）。売上は status が 'delivered' または 'shipped' の注文の明細の quantity * unit_price の合計（送料は含めない）。四半期は 1〜3月が 1、4〜6月が 2、7〜9月が 3、10〜12月が 4 です。売上のない欄は 0 とし、商品のない「季節雑貨」も 0 が並ぶ1行として含めます。列は id, name, q1, q2, q3, q4 の順です。並び順は問いません。

ヒント

categories を親・祖父母と2回 LEFT JOIN し、COALESCE(祖父母の id, 親の id, 自分の id) で最上位のカテゴリIDが求まります（A19 のように再帰CTEでたどってもかまいません）。明細ごとに「最上位カテゴリID・四半期・金額」を CTE で用意し、最上位のカテゴリから LEFT JOIN して、SUM(CASE WHEN 四半期 = 1 THEN 金額 ELSE 0 END) のように列を作ります。

模範解答と解説を見る 
WITH cat_top AS ( SELECT c.id AS category_id, COALESCE(g.id, p.id, c.id) AS top_id FROM categories c LEFT JOIN categories p ON p.id = c.parent_id LEFT JOIN categories g ON g.id = p.parent_id), s AS ( SELECT ct.top_id, (CAST(strftime('%m', o.ordered_on) AS INTEGER) + 2) / 3 AS quarter, oi.quantity * oi.unit_price AS amount FROM orders o JOIN order_items oi ON oi.order_id = o.id JOIN products pr ON pr.id = oi.product_id JOIN cat_top ct ON ct.category_id = pr.category_id WHERE o.status IN ('delivered', 'shipped')) SELECT t.id, t.name, SUM(CASE WHEN s.quarter = 1 THEN s.amount ELSE 0 END) AS q1, SUM(CASE WHEN s.quarter = 2 THEN s.amount ELSE 0 END) AS q2, SUM(CASE WHEN s.quarter = 3 THEN s.amount ELSE 0 END) AS q3, SUM(CASE WHEN s.quarter = 4 THEN s.amount ELSE 0 END) AS q4 FROM categories t LEFT JOIN s ON s.top_id = t.id WHERE t.parent_id IS NULL GROUP BY t.id, t.name

ピボットの前に「どの行をどの列に入れるか」の材料（最上位カテゴリと四半期）を CTE でそろえておくと、本体は CASE を並べるだけになります。親を1段だけたどる COALESCE(p.id, c.id) では、和食器などの3段目の商品が「食器」に集計され、キッチンの売上が少なく出ます。最上位のカテゴリから LEFT JOIN するので、季節雑貨も 0 の行として残ります。
