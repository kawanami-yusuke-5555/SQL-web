初級 8 ORDER BY（複数キー）

部署ごとに給与の高い順

在籍中の社員の一覧を、部署ごと・給与の高い順に並べます。employees テーブル（社員）から、在籍中の社員（退職日 left_on が NULL の社員）を取り出してください。列は id, name, department_id, salary の順です。部署ID（department_id）の小さい順に並べ、同じ部署の中では給与（salary）の高い順に並べます。部署のない社員（department_id が NULL）は先頭に来ます（SQLite の小さい順では NULL が最初に並びます）。

ヒント

ORDER BY には並べ替えのキーをカンマ区切りで複数書けます。1つ目が同じ値のときに2つ目で並べます。向き（ASC / DESC）はキーごとに付けます。

模範解答と解説を見る 
SELECT id, name, department_id, salary FROM employees WHERE left_on IS NULL ORDER BY department_id ASC, salary DESC

ORDER BY department_id, salary DESC は「まず部署IDの小さい順、部署IDが同じなら給与の高い順」です。DESC は直前のキーだけにかかるので、department_id は ASC（省略可）のまま、salary にだけ DESC を付けます。
