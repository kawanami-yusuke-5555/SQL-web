上級 13 LAG・LEAD

前月との売上の差（売上0の月も含める）

2025年1月〜12月の各月について、売上金額・前月の売上金額・前月との差（その月 − 前月）を取り出してください。売上は status が 'delivered' または 'shipped' の注文だけで、金額は quantity * unit_price の合計です（送料は含めません）。customers テーブルとは結合しません。注文が1件もない月（8月）も売上 0 の行として必ず含め、12行にします。そのため 9月の「前月」は 8月（0円）です。1月は前月のデータがないので、前月の売上金額と前月との差は NULL にします。月は '2025-01' の形の文字列で表します。列は 月, 売上金額, 前月の売上金額, 前月との差 の順で、月の順に並べます。

この問題を解く（SQLを書く）

ブラウザだけで動きます。登録は不要です。

ヒント

LAG(列) OVER (ORDER BY 列) で、1行前の値を取り出せます。注文のない月は集計しても行が出てこないので、WITH months(ym) AS (VALUES ('2025-01'), ('2025-02'), …) のように12か月の一覧を作り、月別の売上を LEFT JOIN して COALESCE で 0 にします。

模範解答と解説を見る 
WITH months(ym) AS ( VALUES ('2025-01'), ('2025-02'), ('2025-03'), ('2025-04'), ('2025-05'), ('2025-06'), ('2025-07'), ('2025-08'), ('2025-09'), ('2025-10'), ('2025-11'), ('2025-12')), monthly AS ( SELECT strftime('%Y-%m', o.ordered_on) AS ym, SUM(oi.quantity * oi.unit_price) AS sales FROM orders o JOIN order_items oi ON oi.order_id = o.id WHERE o.status IN ('delivered', 'shipped') GROUP BY ym), filled AS ( SELECT m.ym, COALESCE(s.sales, 0) AS sales FROM months m LEFT JOIN monthly s ON s.ym = m.ym) SELECT ym, sales, LAG(sales) OVER (ORDER BY ym) AS prev_sales, sales - LAG(sales) OVER (ORDER BY ym) AS diff FROM filled ORDER BY ym

LAG は「並び順で1つ前の行」の値を返すので、月が抜けているとその前の月が「前月」として扱われてしまいます。8月の行がないと、9月の比較相手が7月になります。月の一覧を先に作って LEFT JOIN し、売上のない月を 0 で埋めてから LAG を使うのが確実です。LEAD を使うと「次の月」の値になり、比べる向きが逆になります。
