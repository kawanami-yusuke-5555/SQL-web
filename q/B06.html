初級 6 LIKE

「ペン」を含む商品名

商品名に「ペン」を含む商品を、部分一致で検索します。products テーブルから、商品名（name）のどこかに「ペン」という文字の並びを含む商品を、すべて取り出してください。先頭・途中・末尾のどこに含まれていてもかまいません。列は id, name の順です。並び順は問いません。

この問題を解く（SQLを書く）

ブラウザだけで動きます。登録は不要です。

期待される結果

この表と同じ結果になるSQLを書きましょう（列名は違っていても正解になります）。

idname
22ペンダントライト
25ゲルインクボールペン（黒）
26ゲルインクボールペン（赤）
28シャープペンシル
29蛍光ペン5色セット
30筆ペン

6 行

ヒント

LIKE では % が「0文字以上の任意の文字列」を表します。「どこかに含む」は前後の両方に % を付けます。

模範解答と解説を見る 
SELECT id, name FROM products WHERE name LIKE '%ペン%'

'%ペン%' は前後に何があっても（何もなくても）「ペン」を含めば一致します。LIKE は文字の並びだけを見るので、ペンではない「ペンダントライト」も一致する点に注意しましょう。'ペン%' だと先頭一致、'%ペン' だと末尾一致になります。
