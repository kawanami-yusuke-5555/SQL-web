初級 7 IS NULL

メールアドレス未登録の会員

メールアドレスが未登録の会員を探します。customers テーブルから、メールアドレス（email）が登録されていない（NULL の）会員を取り出してください。列は id, name の順です。並び順は問いません。

この問題を解く（SQLを書く）

ブラウザだけで動きます。登録は不要です。

期待される結果

この表と同じ結果になるSQLを書きましょう（列名は違っていても正解になります）。

idname
5伊藤 さくら
14佐々木 恵
23森 隆
35村上 涼
48岡本 蓮

5 行

ヒント

NULL は「値がない」ことを表す特別な印で、= では比べられません。

模範解答と解説を見る 
SELECT id, name FROM customers WHERE email IS NULL

NULL かどうかは IS NULL（NULL でないことは IS NOT NULL）で調べます。email = NULL と書くと、比較の結果が「不明（NULL）」になって どの行も選ばれず、0 行になります。
