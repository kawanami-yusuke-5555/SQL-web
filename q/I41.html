中級 41 日付・文字列関数

原価の表示ラベルを作る（||）

文字列をつなげて、商品の表示用ラベルを作ります。products テーブルのカテゴリID（category_id）が 8（筆記具）の商品について、「商品名: 原価円」という表示用の文字列を作ってください。例えば シャープペンシル なら 'シャープペンシル: 180円' です（コロンは半角で、後ろに半角スペースを1つ入れます）。原価（cost）が NULL の商品は '筆ペン: 未設定' のように、原価の部分を「未設定」にします（「円」は付けません）。列は id, ラベル の順です。並び順は問いません。

この問題を解く（SQLを書く）

ブラウザだけで動きます。登録は不要です。

期待される結果

この表と同じ結果になるSQLを書きましょう（列名は違っていても正解になります）。

idlabel
25ゲルインクボールペン（黒）: 60円
26ゲルインクボールペン（赤）: 60円
27万年筆: 5000円
28シャープペンシル: 180円
29蛍光ペン5色セット: 220円
30筆ペン: 未設定

6 行

ヒント

文字列は || でつなげます。ただし、つなぐものに NULL が1つでもあると結果全体が NULL になります。COALESCE で NULL のときの文字列を用意しましょう。

模範解答と解説を見る 
SELECT id, name || ': ' || COALESCE(cost || '円', '未設定') AS label FROM products WHERE category_id = 8

|| は文字列の連結で、数値もそのまま文字列としてつながります。cost が NULL だと cost || '円' は NULL になるので、COALESCE で '未設定' に置き換えます。COALESCE を付けないと筆ペンのラベルが NULL になります。concat 関数は NULL を空文字として扱うので、'筆ペン: 円' になってしまいます。
