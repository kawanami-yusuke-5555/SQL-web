上級 22 グループ内上位N件

四半期ごとの売上上位3商品

2025年の四半期（1〜3月が 1、4〜6月が 2、7〜9月が 3、10〜12月が 4）ごとに、売上金額の多い商品の上位 3 件を求めてください。売上金額は、status が 'delivered' または 'shipped' の注文の明細の quantity * unit_price の合計です（送料は含めず、unit_price は注文時点の単価なので products.price は使いません）。同じ四半期で売上金額が同じなら product_id の小さい方を上位とします（上位3件の境界に同額はありません）。列は quarter（整数）, rank（1〜3 の整数）, product_id, name, sales の順です。quarter の小さい順、同じ四半期の中では rank の小さい順に並べます。

ヒント

四半期は月の番号から (月 + 2) / 3 の整数の割り算で求められます（月は CAST(strftime('%m', ordered_on) AS INTEGER)）。CTE で「四半期 × 商品」の売上を集計してから、ROW_NUMBER() OVER (PARTITION BY 四半期 ORDER BY 売上 DESC, product_id) で順位を付けます。

模範解答と解説を見る 
WITH q AS ( SELECT (CAST(strftime('%m', o.ordered_on) AS INTEGER) + 2) / 3 AS quarter, oi.product_id, SUM(oi.quantity * oi.unit_price) AS sales FROM orders o JOIN order_items oi ON oi.order_id = o.id WHERE o.status IN ('delivered', 'shipped') GROUP BY quarter, oi.product_id), ranked AS ( SELECT quarter, product_id, sales, ROW_NUMBER() OVER (PARTITION BY quarter ORDER BY sales DESC, product_id) AS rn FROM q) SELECT r.quarter, r.rn AS rank, r.product_id, p.name, r.sales FROM ranked r JOIN products p ON p.id = r.product_id WHERE r.rn <= 3 ORDER BY r.quarter, r.rn

「集計してから順位を付ける」ときは、集計を CTE に分けると読みやすくなります。PARTITION BY quarter を忘れると、年間を通した順位になって上位3件しか残りません。値上げのあった鉄のフライパンなどは products.price で計算すると実際の売上と変わり、キャンセル注文を含めると第4四半期の順位が入れ替わります。
