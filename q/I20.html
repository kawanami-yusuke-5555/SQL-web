中級 20 NULL処理

家具の注文数量（一度も注文されていない商品は 0）

家具の商品ごとの注文数量を、注文のない商品は 0 として求めます。家具カテゴリ（products.category_id が 6）の全ての商品について、注文された数量（order_items.quantity）の合計を取り出してください。status は問わず、キャンセル・返品も含めたすべての注文明細を数えます。一度も注文されていない商品も含め、その合計は NULL ではなく 0 にします。列は products.id, products.name, 数量の合計 の順です。並び順は問いません。

この問題を解く（SQLを書く）

ブラウザだけで動きます。登録は不要です。

期待される結果

この表と同じ結果になるSQLを書きましょう（列名は違っていても正解になります）。

idnameCOALESCE(SUM(oi.quantity), 0)
17木製スツール5
18折りたたみテーブル2
19ブックシェルフ0
20座椅子4
36収納ボックス11

5 行

ヒント

商品を全部残すには products を左にした LEFT JOIN です。明細のない商品は SUM の結果が NULL になるので、COALESCE で 0 に置き換えます。

模範解答と解説を見る 
SELECT p.id, p.name, COALESCE(SUM(oi.quantity), 0) FROM products AS p LEFT JOIN order_items AS oi ON oi.product_id = p.id WHERE p.category_id = 6 GROUP BY p.id, p.name

SUM は合計する値がすべて NULL（または0行）のとき、0 ではなく NULL を返します。LEFT JOIN で明細のない商品はまさにこの状態なので、COALESCE(SUM(...), 0) で 0 にします。INNER JOIN では注文されていない商品が消え、COUNT(*) にすると数量ではなく明細の行数になります（明細のない商品も 1 になります）。
