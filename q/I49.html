中級 49 集合演算

今の定価と違う単価で売れた商品（EXCEPT）

今の定価とは違う単価で売れたことのある商品を探します。order_items テーブル（注文明細）に記録された「商品ID（product_id）と販売単価（unit_price）の組み合わせ」のうち、products テーブルの「商品ID（id）と現在の定価（price）の組み合わせ」と一致しないものを、重複なしで取り出してください。注文の status は問いません。列は product_id, unit_price の順です。並び順は問いません。

この問題を解く（SQLを書く）

ブラウザだけで動きます。登録は不要です。

期待される結果

この表と同じ結果になるSQLを書きましょう（列名は違っていても正解になります）。

product_idunit_price
115200
31280
331000

3 行

ヒント

A EXCEPT B は「A にあって B にない行」を返します。比べるのは行全体なので、2列を並べた SELECT どうしで EXCEPT すると、組み合わせで比べられます。

模範解答と解説を見る 
SELECT product_id, unit_price FROM order_items EXCEPT SELECT id, price FROM products

EXCEPT は列の組み合わせ（行全体）で比べ、結果の重複も取り除きます。価格改定前の単価や、値下げ販売の単価が見つかります。product_id だけで EXCEPT すると「どの商品も products にある」ので 0 行になります。左右を逆にすると「一度もその定価で売れていない商品」という別の意味になります。
