中級 25 CASE式

調理器具の上半期・下半期の販売数量

調理器具の商品ごとに、上半期と下半期の販売数量を横に並べて比べます。調理器具のカテゴリ（products.category_id が 5）の各商品について、2025年の上半期（ordered_on が 2025-01-01〜2025-06-30）と下半期（2025-07-01〜2025-12-31）の販売数量（order_items.quantity の合計）を、横に並べて取り出してください。対象は status が 'delivered' または 'shipped' の注文だけです。販売のない期間は 0 を出します（この条件で販売が1件もない調理器具はないので、INNER JOIN でかまいません）。列は products.id, products.name, 上半期の数量, 下半期の数量 の順です。並び順は問いません。

この問題を解く（SQLを書く）

ブラウザだけで動きます。登録は不要です。

期待される結果

この表と同じ結果になるSQLを書きましょう（列名は違っていても正解になります）。

ヒント

orders・order_items・products を結合し、商品ごとに GROUP BY します。期間ごとの数量は SUM(CASE WHEN 期間の条件 THEN oi.quantity ELSE 0 END) で分けて合計します。

模範解答と解説を見る 
SELECT p.id, p.name, SUM(CASE WHEN o.ordered_on < '2025-07-01' THEN oi.quantity ELSE 0 END), SUM(CASE WHEN o.ordered_on >= '2025-07-01' THEN oi.quantity ELSE 0 END) FROM order_items AS oi INNER JOIN orders AS o ON o.id = oi.order_id INNER JOIN products AS p ON p.id = oi.product_id WHERE p.category_id = 5 AND o.status IN ('delivered', 'shipped') GROUP BY p.id, p.name

THEN に 1 ではなく oi.quantity を書くと、条件に合う行の数量だけを合計できます。ELSE 0 があるので、その期間に販売がない商品も 0 になります。期間の境目（6月30日と7月1日）を <= '2025-07-01' などと取り違えると、7月1日の注文が上半期に入ります。status の条件を忘れるとキャンセル・返品の数量も入ります。
