直近3回の注文金額の移動平均（フレーム指定）

会員ID が 1 の会員の注文について、注文の金額と、「その注文を含む直近3回の注文」の金額の平均（移動平均）を取り出してください。対象は status が 'delivered' または 'shipped' の注文だけで、注文の金額は明細の quantity * unit_price の合計です（送料は含めません）。直近3回は、注文日の古い順に並べたときの「今の注文と、その直前の2回」です。最初の注文は1回分、2回目の注文は2回分の平均になります。移動平均は小数点以下を四捨五入して ROUND(値) で整数の桁にします。列は 注文ID（orders.id）, ordered_on, 注文の金額, 移動平均 の順で、注文日の古い順に並べます（この会員に同じ日の注文はありません）。

ヒント

ウィンドウ関数では、OVER の中に ROWS BETWEEN 2 PRECEDING AND CURRENT ROW と書くと、集計の範囲を「2行前から今の行まで」に限定できます（フレーム指定）。

模範解答と解説を見る 
WITH order_totals AS ( SELECT o.id, o.ordered_on, SUM(oi.quantity * oi.unit_price) AS total FROM orders o JOIN order_items oi ON oi.order_id = o.id WHERE o.status IN ('delivered', 'shipped') AND o.customer_id = 1 GROUP BY o.id, o.ordered_on) SELECT id, ordered_on, total, ROUND(AVG(total) OVER (ORDER BY ordered_on, id ROWS BETWEEN 2 PRECEDING AND CURRENT ROW)) AS moving_avg FROM order_totals ORDER BY ordered_on, id

フレーム指定 ROWS BETWEEN 2 PRECEDING AND CURRENT ROW は「2行前・1行前・今の行」の3行だけを集計の範囲にします。先頭の2行は前の行が足りないので、ある行だけで平均します。フレームを書かないと範囲は「先頭から今の行まで」になり、移動平均ではなく累積の平均になります。3 PRECEDING にすると4回分の平均になるので、「直近 n 回」は n - 1 PRECEDING と書く点に注意します。
