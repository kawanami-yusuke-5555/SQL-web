上級 17 再帰CTE

キッチンの配下のカテゴリをすべて

階層になったカテゴリを、再帰CTE で上から下までたどります。categories テーブル（parent_id が親カテゴリのID）から、カテゴリ「キッチン」（id = 1）と、その配下にあるすべてのカテゴリ（子・孫…）を取り出してください。列は id, name, depth の順です。depth はキッチンからの深さで、キッチン自身を 0、その子を 1、孫を 2 とします。並び順は問いません。

この問題を解く（SQLを書く）

ブラウザだけで動きます。登録は不要です。

期待される結果

この表と同じ結果になるSQLを書きましょう（列名は違っていても正解になります）。

idnamedepth
1キッチン0
5調理器具1
4食器1
10和食器2
11洋食器2

5 行

ヒント

WITH RECURSIVE の最初の行を「id = 1 のカテゴリ（depth 0）」にし、次の行は「parent_id が直前に見つけたカテゴリの id であるカテゴリ（depth + 1）」として categories を JOIN します。

模範解答と解説を見る 
WITH RECURSIVE sub(id, name, depth) AS ( SELECT id, name, 0 FROM categories WHERE id = 1 UNION ALL SELECT c.id, c.name, s.depth + 1 FROM categories c JOIN sub s ON c.parent_id = s.id) SELECT id, name, depth FROM sub

自己結合を1回するだけでは「子」までしか届かず、孫の和食器・洋食器が漏れます。再帰CTEなら、新しい行が見つからなくなるまで JOIN を繰り返すので、階層が何段あっても配下をすべてたどれます。
