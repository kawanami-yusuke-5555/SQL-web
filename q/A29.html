初回購入月ごとのリピート率

初回購入月ごとに、リピーターの人数とリピート率を求めます。customers テーブルにいる顧客を、有効な注文（status が 'delivered' または 'shipped'）を初めてした月（初回購入月）でグループに分け、グループごとの人数と、有効な注文が2件以上ある顧客（リピーター）の人数・割合を求めてください。有効な注文が1件もない顧客は含めません。customers に存在しない顧客ID の注文（order 69）も含めません。列は first_month（'2025-01' の形式の文字列）, customers, repeaters, repeat_rate の順です。repeat_rate は repeaters / customers × 100 を小数第1位に ROUND した値（例: 80.0）です。first_month の古い順に並べます。

ヒント

1つ目の CTE で、customers と JOIN した有効な注文から、顧客ごとの最初の注文日（MIN）と有効な注文件数（COUNT）を求めます。それを初回購入月で GROUP BY し、SUM(CASE WHEN 件数 >= 2 THEN 1 ELSE 0 END) でリピーターを数えます。割合は 100.0 を掛けてから割ると、整数の割り算（切り捨て）になりません。

模範解答と解説を見る 
WITH valid AS ( SELECT o.customer_id, o.ordered_on FROM orders o JOIN customers c ON c.id = o.customer_id WHERE o.status IN ('delivered', 'shipped')), firsts AS ( SELECT customer_id, MIN(ordered_on) AS first_on, COUNT(*) AS order_count FROM valid GROUP BY customer_id) SELECT strftime('%Y-%m', first_on) AS first_month, COUNT(*) AS customers, SUM(CASE WHEN order_count >= 2 THEN 1 ELSE 0 END) AS repeaters, ROUND(100.0 * SUM(CASE WHEN order_count >= 2 THEN 1 ELSE 0 END) / COUNT(*), 1) AS repeat_rate FROM firsts GROUP BY first_month ORDER BY first_month

「顧客ごとに集計（初回の月と件数）」→「その結果を月ごとに集計」と、2段階の GROUP BY を CTE でつないでいます。条件付きの数え上げには CASE 式を使います。キャンセルだけの顧客（customer 43）を含めると10月の人数が増え、存在しない顧客の注文を含めると5月の人数が増えます。整数どうしの割り算 repeaters / customers は 0 か 1 に切り捨てられます。
