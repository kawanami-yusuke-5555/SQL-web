会員の多い都道府県順

都道府県ごとの会員数を数え、多い順に並べます。customers テーブルから、都道府県（prefecture）ごとの会員の数を取り出してください。列は prefecture, 会員の数 の順です。会員の数の多い順に並べ、同じ数のときは prefecture の昇順（ORDER BY prefecture で並ぶ順）にします。同じ人が二重に登録されている会員も、別の会員として数えます。

この問題を解く（SQLを書く）

ブラウザだけで動きます。登録は不要です。

ヒント

ORDER BY には COUNT(*) のような集計の式（または SELECT で付けた別名）を書けます。2つ目のキーで同数の並び方を決めます。

模範解答と解説を見る 
SELECT prefecture, COUNT(*) AS cnt FROM customers GROUP BY prefecture ORDER BY cnt DESC, prefecture

ORDER BY は GROUP BY と集計のあとに処理されるので、集計した値で並べ替えられます。会員の数が同じ都道府県が多いため、2つ目のキー prefecture がないと並び順が決まりません。DESC を付け忘れると少ない順になります。
