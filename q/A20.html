上級 20 グループ内上位N件

カテゴリごとの高額商品 上位2件（廃番を除く）

カテゴリごとに、価格の高い商品を上位 2 件ずつ取り出します。products テーブルから、廃番でない商品（is_discontinued が 0）だけを対象に、カテゴリ（category_id）ごとに価格（price）の高い順で上位 2 件の商品を取り出してください。廃番の商品を除いたうえで順位を付けるので、どのカテゴリも商品が2つ以上あれば必ず2件になります（商品が1つのカテゴリは1件）。上位2件の中と境界に同じ価格の商品はありません。列は category_id, id, name, price の順です。category_id の小さい順、同じカテゴリの中では price の高い順に並べます。

ブラウザだけで動きます。登録は不要です。

ヒント

ROW_NUMBER() OVER (PARTITION BY category_id ORDER BY price DESC) でカテゴリ内の順位を付け、外側のクエリで順位が 2 以下の行を選びます。ウィンドウ関数の結果は同じクエリの WHERE では使えないので、CTE か FROM 句の副問い合わせに入れます。廃番の除外は、順位を付ける前に行います。

模範解答と解説を見る 
WITH ranked AS ( SELECT category_id, id, name, price, ROW_NUMBER() OVER (PARTITION BY category_id ORDER BY price DESC) AS rn FROM products WHERE is_discontinued = 0) SELECT category_id, id, name, price FROM ranked WHERE rn <= 2 ORDER BY category_id, price DESC

グループ内の上位N件は「PARTITION BY で区切って順位を付け、外側で順位 <= N を選ぶ」のが定番です。WHERE is_discontinued = 0 を外側（順位を付けた後）に書くと、廃番の土鍋6号や2025年手帳が順位を1つ占めたまま除かれ、そのカテゴリは1件しか残りません。
