中級 34 サブクエリ（副問い合わせ）

商品ごとのレビュー件数と平均評価

商品ごとのレビュー件数と平均評価を求めます。products テーブルのカテゴリID（category_id）が 5（調理器具）の商品について、レビュー件数と平均評価を求めてください。列は id, name, レビュー件数, 平均評価 の順です。平均評価は rating の平均を ROUND で小数第2位に丸めます。レビューが1件もない商品も含め、その場合のレビュー件数は 0、平均評価は NULL とします。並び順は問いません。

この問題を解く（SQLを書く）

ブラウザだけで動きます。登録は不要です。

期待される結果

この表と同じ結果になるSQLを書きましょう（列名は違っていても正解になります）。

idnamereview_countavg_rating
11鉄のフライパン26cm74
12ステンレス片手鍋33
13木製まな板44.5
14シリコンへら23.5
15計量スプーンセット0NULL
16土鍋6号0NULL
40ホーローケトル12

7 行

ヒント

SELECT の列の中に、外側の商品 p.id を使った副問い合わせ (SELECT COUNT(*) FROM reviews r WHERE r.product_id = p.id) を書けます。平均評価も同じ形で書けます。

模範解答と解説を見る 
SELECT p.id, p.name, (SELECT COUNT(*) FROM reviews r WHERE r.product_id = p.id) AS review_count, (SELECT ROUND(AVG(r.rating), 2) FROM reviews r WHERE r.product_id = p.id) AS avg_rating FROM products p WHERE p.category_id = 5

SELECT 句の相関副問い合わせは、商品1行ごとにレビューを数えるので、レビューのない商品でも COUNT(*) が 0 になって行が残ります（AVG は対象がないので NULL）。INNER JOIN してから GROUP BY すると、レビューのない計量スプーンセットと土鍋6号が消えます。LEFT JOIN でも COUNT(*) にすると 0 ではなく 1 になります。
