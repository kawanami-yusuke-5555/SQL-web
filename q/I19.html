中級 19 NULL処理

社員の部署名（未配属は「未配属」）

社員ごとの部署名を出し、部署のない社員は「未配属」と表示します。employees テーブル（社員）の在籍中の社員（left_on が NULL）全員について、社員ID・名前・部署名を取り出してください。部署名は departments テーブルの name です。部署のない社員（department_id が NULL）も含め、その部署名は文字列 '未配属' にします。列は employees.id, employees.name, 部署名 の順です。並び順は問いません。

この問題を解く（SQLを書く）

ブラウザだけで動きます。登録は不要です。

ヒント

部署のない社員も残すには LEFT JOIN を使います。相手が見つからなかった行の d.name は NULL になるので、それを置き換えます。

模範解答と解説を見る 
SELECT e.id, e.name, COALESCE(d.name, '未配属') FROM employees AS e LEFT JOIN departments AS d ON d.id = e.department_id WHERE e.left_on IS NULL

LEFT JOIN で相手が見つからなかった行は、相手側の列がすべて NULL になります。COALESCE でその NULL を '未配属' に置き換えます。INNER JOIN では部署のない社員が消え、COALESCE を付けないと部署名が NULL のまま出ます。
