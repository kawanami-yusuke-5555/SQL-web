月別・ステータス別の注文件数を横に並べる

月ごとの注文件数を、状態（status）別に横に並べた集計表にします。orders テーブルから、注文のある月ごとに、status 別の注文件数を1行に横に並べてください（注文のない2025年8月は含めません）。列は month（'2025-01' の形式の文字列）, delivered, shipped, cancelled, returned, total の順です。delivered 〜 returned はそれぞれの status の件数、total はその月の全注文の件数です。件数がない status は NULL ではなく 0 にします。month の古い順に並べます。

この問題を解く（SQLを書く）

ブラウザだけで動きます。登録は不要です。

この表と同じ結果になるSQLを書きましょう（列名は違っていても正解になります）。

ヒント

GROUP BY で月ごとにまとめ、SUM(CASE WHEN status = 'delivered' THEN 1 ELSE 0 END) のように、列ごとに条件付きで数えます。ELSE 0 を書かないと、該当する行がない月は NULL になります。

模範解答と解説を見る 
SELECT strftime('%Y-%m', ordered_on) AS month, SUM(CASE WHEN status = 'delivered' THEN 1 ELSE 0 END) AS delivered, SUM(CASE WHEN status = 'shipped' THEN 1 ELSE 0 END) AS shipped, SUM(CASE WHEN status = 'cancelled' THEN 1 ELSE 0 END) AS cancelled, SUM(CASE WHEN status = 'returned' THEN 1 ELSE 0 END) AS returned, COUNT(*) AS total FROM orders GROUP BY month ORDER BY month

縦に並んだ「月 × status」の件数を、CASE 式で列に振り分けて横に並べるのがピボットです。値の種類ごとに1列ずつ CASE を書きます。COUNT(CASE WHEN … THEN 1 ELSE 0 END) は 0 も「NULL でない値」として数えるので、どの列も total と同じになってしまいます。COUNT を使うなら ELSE を書かずに NULL にします。
