上級 16 再帰CTE

注文のない月も含めた月別の注文件数

注文のない月も 0 件として含めた、月別の注文件数の表を作ります。orders テーブルから、2025年1月〜12月の各月の注文件数を求めてください。status は問わず、キャンセル・返品も1件と数えます。2025年8月は注文が1件もありませんが、この月も注文件数 0 として1行に含めます（12 行になります）。列は month（'2025-01' の形式の文字列）, order_count の順です。month の古い順に並べます。

この問題を解く（SQLを書く）

ブラウザだけで動きます。登録は不要です。

この表と同じ結果になるSQLを書きましょう（列名は違っていても正解になります）。

ヒント

注文のない月は orders に1行もないため、GROUP BY だけでは出てきません。WITH RECURSIVE で 2025-01 から 2025-12 までの月の一覧を作り、orders を LEFT JOIN します。LEFT JOIN 後に件数を数えるときは COUNT(*) ではなく COUNT(orders の列) を使います。

模範解答と解説を見る 
WITH RECURSIVE months(month_start) AS ( SELECT '2025-01-01' UNION ALL SELECT date(month_start, '+1 month') FROM months WHERE month_start < '2025-12-01') SELECT strftime('%Y-%m', m.month_start) AS month, COUNT(o.id) AS order_count FROM months m LEFT JOIN orders o ON strftime('%Y-%m', o.ordered_on) = strftime('%Y-%m', m.month_start) GROUP BY m.month_start ORDER BY m.month_start

再帰CTEは「最初の行（UNION ALL の前）」から始め、「前の行から次の行を作る部分（UNION ALL の後）」を WHERE の条件が偽になるまで繰り返します。こうして作った月の一覧を基準に LEFT JOIN すると、注文のない8月も行として残ります。COUNT(*) にすると、8月の「相手のいない1行」まで数えて 1 になってしまいます。
