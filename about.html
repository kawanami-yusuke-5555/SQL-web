このサイトについて

SQL練習帳は、データ分析を始めたい社会人のための SQL の練習問題集です。会員登録やインストールは要りません。ブラウザの中で SQL（SQLite）を動かすので、書いた SQL や練習用のデータがどこかへ送られることもありません。

特徴

  • 全100問（初級10・中級50・上級30・実践10）。すべて登録なしで解けます。
  • 初級〜上級は「期待される結果」の表を見ながら SQL を書き、自動で答え合わせをします。列名（AS で付ける名前）が違っても、結果の値が同じなら正解です。並び順を指定している問題だけは順番も比べます。
  • 実践問題は、業務でよくある「あいまいな依頼」に答える練習です。決まった正解はないので、チェックポイントと解答例で自分の結果を確かめ、「完了」にします。
  • 練習用のデータには、注文のない顧客・NULL・キャンセルされた注文・同じ値の並びなど、実際のデータでつまずきやすい点をわざと入れています。

練習用のデータ

雑貨のネットショップを運営する会社の、2025年1年分のデータです（商品・カテゴリ・顧客・注文・注文明細・レビュー・部署・社員の8テーブル）。問題文の「今日」は 2026年1月1日です。データはすべて架空のもので、実在の人物・団体とは関係ありません。

使い方

  1. トップページの一覧から問題を選ぶ（「解く」でそのまま解答画面が開きます）
  2. SQL を書いて「実行」（Ctrl+Enter）し、結果を「期待される結果」と比べる
  3. 「答え合わせ」で判定する。困ったら「ヒント」「模範解答と解説」を開く

進捗（解いた問題）は、お使いのブラウザの中だけに保存されます。別のブラウザや端末とは共有されません。

扱う SQL は SELECT 文（WITH 句を含む）だけです。データベースは SQLite（sql.js）なので、日付の関数など一部の書き方は MySQL・PostgreSQL などと異なります。

動作環境

Edge・Chrome・Firefox・Safari の最近の版。スマートフォンでも使えますが、SQL を書くにはパソコンが便利です。SQL を動かす仕組み（sql.js）をインターネットから読み込むため、接続が必要です。
